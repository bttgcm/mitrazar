# Aim
This projects aims at coding a website for a video-photographer. 

# Description
The initial page shows the world as a globe with pins on the location where photo/video where taken.
Once the viewer clicks on a pin, a pop-up overlaying the globe shows content made of text and image thumbs. 
If images are clicked they will be enlarged.
If video thumb are clicked they will be enlarged and will show a video player.
The top menu should show an ABOUT page link as well and a COLLABORATE page link

# Structure
Make the website easy to update. 
- each location data should be contined in a separate folder with .txt file for the main text, photos and vidoe file or links
- adding content to the folder should be automatically detected and inserted in the page
